# 待优化功能点

## 1. 高优先级

### 1. SVG 替换保真继续增强

- 当前已经保留位置、尺寸、旋转、名称和基础超链接
- `v0.6.1` 已在 URL 模式自动启用 `simpleLabels`
- 仍建议继续增强：
  - 动画完整迁移
  - 更多 `ActionSettings` 场景
  - 更复杂的格式与层级保留

### 2. Desktop 模式的 `simpleLabels` 自动化

- 当前 URL 模式已能由插件自动下发 `{ "simpleLabels": true }`
- Desktop 模式仍依赖外部 draw.io Desktop 自身配置
- 可继续探索：
  - 是否存在安全可靠的桌面配置写入方式
  - 是否能在首次检测桌面编辑器时给出一次性引导
  - 是否能在导出链路中进一步验证 SVG 标签渲染质量

### 3. 发布安装体验升级

- 当前已有发布包、`install.cmd` 和 PowerShell 安装脚本
- 仍建议补：
  - 更直观的一键安装界面
  - 安装后快捷入口
  - 版本升级与覆盖安装提示

### 4. URL 模式真实远端兼容矩阵

- 当前已经有 `Test URL` 和 URL 烟雾测试
- 仍建议补：
  - 官方 `embed.diagrams.net` 验证矩阵
  - 私有部署版本兼容说明
  - 代理/证书/跨域问题收敛

## 2. 中优先级

### 5. Sidecar 路径自动重定位

- 当前 sidecar 适合跟随 PPT 同目录保存
- 仍建议支持：
  - PPT 另存为后自动重建路径
  - 目录移动后的恢复提示
  - 缺失 sidecar 时的更智能恢复流程

### 6. 批量操作能力

- 当前以单图形操作为主
- 可补：
  - 批量刷新
  - 批量重新绑定
  - 批量检查损坏图形

### 7. 诊断面板

- 当前主要依赖日志文件
- 可补：
  - 设置页中的“打开日志目录”
  - 最近一次错误摘要
  - 文档内图形与 `CustomXMLPart` 状态检查

## 3. 低优先级

### 8. 图形管理视图

- 展示当前演示文稿中所有受管理图形
- 可按 `diagramId`、页码、更新时间筛选

### 9. XML 恢复工具

- 当 shape 元数据损坏时
- 可尝试从 SVG `content` 元数据恢复

### 10. 用户体验细节

- 更友好的提示文案
- 更清晰的设置说明
- 关键动作前后的状态提示

## 4. 暂不在本阶段内

### 11. WPS 适配

- 当前版本明确只做 PowerPoint Desktop
- 如果后续进入 WPS，需要单独做宿主适配层

### 12. 云同步与协作

- 当前没有做共享存储和多人冲突解决
- 这会显著扩大产品边界，建议后续单独规划
