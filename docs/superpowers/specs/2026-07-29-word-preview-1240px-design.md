# Word 1240px 清晰预览设计

## 目标

在不恢复 Word 复杂 SVG 原生渲染、不增加被动选区处理的前提下，把 Word 中 Draw.io 展示图的正常 PNG 预览宽度从 620px 提升到 1240px，改善文字与细线清晰度。PowerPoint 继续直接使用原始 SVG。

## 约束

- “不卡”优先级最高：Word 仍使用 PNG 浮动 `Shape`、`wdWrapFront` 和“选中后点击命令编辑”。
- 不改成 3 倍位图，不引入自适应 DPI 或新的配置项。
- 保持源宽高比、零边框，不拉伸、不裁剪、不强制 1:1。
- Draw.io Desktop 导出失败时的轻量占位图也使用同一 1240px 基准；极端纵横比仍受现有 1200px 高度上限保护。
- 使用用户提供的复杂 Draw.io 源码，在含 150 个正文段落、表格和辅助图片的真实 Word 文档中验证。

## 实现

`WordPreviewImageProvider` 的唯一清晰度参数由 620 改为 1240。创建、重新编辑和刷新继续共用该提供器，因此三条路径保持一致。现有图片物理显示尺寸、锚点、环绕方式、元数据和显式编辑流程均不改变。

## 验收

1. 提供器真实导出宽度为 1240px，宽高比与源图一致，且不是 1:1。
2. 2:1 回归样本导出失败时生成 1240×620 的等比例轻量 PNG，不回退复杂 SVG。
3. Release x64 构建和现有自动化回归通过。
4. 用户复杂源图在富文档中生成 1240px 等比例 PNG，无边框留白。
5. 真实 Word 中完成选择、连续拖动、调整大小、重新编辑检查；不接受因插件被动元数据路径引入的卡顿。
6. 重新打包并更新本地安装，安装态 DLL 与最新源码构建哈希一致。
