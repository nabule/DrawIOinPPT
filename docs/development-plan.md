# 详细开发计划

## 1. 范围

首个正式目标版本是 PowerPoint Desktop 单宿主版本，不考虑 WPS。

必须覆盖的业务能力：

1. 在 PPT 中插入 Draw.io 图形，并保持矢量显示。
2. 选中图形后可以重新编辑。
3. 编辑器支持本地路径或 URL 配置。
4. 原始 Draw.io XML 随 PPT 一起保存。

## 2. 当前状态

当前仓库已经完成 `M0 - 初始版本骨架`，并完成了 `M1`、`M2` 与 `M3` 的首版闭环：

- 项目结构建立
- 开发计划落地
- 数据模型与序列化落地
- PowerPoint Add-in 宿主入口建立
- Ribbon 与选中图形监听骨架建立
- 本地 draw.io 桌面版联动闭环
- URL 模式编辑器首版接入

## 3. 里程碑

### M0：初始版本骨架

状态：已完成

交付内容：

- 解决方案与项目目录
- COM Add-in 入口
- Ribbon 按钮定义
- 选择监听骨架
- 元数据包与设置模型
- 开发脚本与文档

### M1：元数据 MVP

状态：已完成（首版）

目标：

- 选中单个图形时识别插件元数据
- 为图形写入 `DRAWIO_PPT_ID`
- 将元数据包写入 `AlternativeText`
- 从现有 shape 中还原元数据包

验收标准：

- 选中带元数据的图形时，插件能正确识别并显示状态
- 元数据可在保存 PPT 后再次读取

当前进展：

- 已支持把元数据写入选中的单个图形
- 已支持清除图形绑定
- 已支持从选中的图形还原元数据并刷新 Ribbon 状态
- 已支持通过新建流程生成带元数据的图形

### M2：SVG 插入与替换

状态：已完成（首版）

目标：

- 能把外部生成的 SVG 插入当前幻灯片
- 能替换现有插件图形的显示内容
- 更新时保留位置、尺寸和旋转

验收标准：

- 插入后的图形在 PPT 中保持矢量显示
- 替换后布局不跳动

当前进展：

- 已支持在当前幻灯片插入新的 SVG 图形
- 已支持替换现有已绑定图形，并保留位置、尺寸、旋转和基本层级
- 已支持手动刷新选中图形
- 已接入桌面模式下的 `.drawio` 文件轮询监控，保存后会尝试自动刷新
- 已支持双击已绑定图形唤起编辑器
- 已支持按设置启用选中即打开编辑器
- 已支持自动探测常见安装位置下的桌面编辑器路径

### M3：本地 draw.io 模式

状态：已完成（首版）

目标：

- 配置本地编辑器路径
- 生成临时 `.drawio` 文件
- 启动桌面版 draw.io
- 在关闭或保存后回写

验收标准：

- 本地路径可配置并持久化
- 保存后可以回写 SVG 与元数据

当前进展：

- 已支持配置和自动探测本地桌面编辑器路径
- 已支持生成或复用 `.drawio` 工作文件
- 已支持启动桌面版 `draw.io` / `diagrams.net`
- 已支持在保存后自动刷新 PPT 中的 SVG 图形
- 已验证桌面版 CLI 导出 SVG 的兼容参数

### M4：URL 模式

状态：进行中

目标：

- 配置可用的 diagrams.net URL
- 嵌入或弹窗打开编辑器
- 实现 XML 的 load/save 通道

验收标准：

- URL 模式可正常打开已有图形
- 保存后可更新 PPT 中图形

当前进展：

- 已接入 `WebView2` 宿主页
- 已接入 diagrams.net embed iframe
- 已打通 `init -> load -> save -> export` 的宿主消息编排代码
- 已支持把 URL 编辑器返回的 SVG 与 XML 回写到 PPT 图形

### M5：自动更新与稳定化

目标：

- 文件监听
- 异常处理
- 日志记录
- 插件安装说明
- 回归测试清单

验收标准：

- 插件遇到异常时不会破坏现有 PPT 内容
- 常见操作路径都有可追踪日志

## 4. 推荐开发顺序

1. 先完成 M1，让“识别和保存元数据”闭环稳定。
2. 再做 M2，把 SVG 插入与替换做通。
3. 再接 M3，本地编辑器链路优先。
4. 最后再做 M4 的 URL 模式。

## 6. 风险拆解

### 高风险

- SVG 替换后对象属性丢失
- 大型 XML 写入 `AlternativeText` 触发边界问题
- 外部编辑器保存时机不稳定

### 中风险

- 不同版本 PowerPoint 对 SVG 行为差异
- 本地 draw.io 启动参数差异

### 低风险

- 设置持久化
- Ribbon 状态刷新

## 7. 版本建议

- `v0.1.0-initial`：仓库初始化与宿主骨架
- `v0.2.0-metadata`：元数据闭环
- `v0.3.0-svg`：SVG 插入与替换
- `v0.4.0-desktop-editor`：本地 draw.io 联动
- `v0.5.0-url-editor`：URL 模式
- `v0.6.0-stable`：稳定化与发布准备
