# v0.1.0-initial

[中文首页](../README.md) | [English Overview](../README.en.md)

这是仓库的第一个初始化版本，目标不是功能完备，而是把后续开发的地基一次搭好。

## 这版先解决什么问题

- 项目还没有统一的插件架构、数据模型和开发路线，后续功能容易各做各的。
- PowerPoint 插件需要先有可构建、可注册、可扩展的基础骨架，才能继续接入 draw.io 编辑和回写。
- 后续每个阶段需要有明确验收标准，避免只写代码但不知道是否能交付。

本版本包含：

- PowerPoint 原生 COM Add-in 技术路线定稿
- 详细开发计划与阶段验收标准
- 核心数据模型与元数据包序列化
- 插件设置存储模型
- Ribbon 骨架
- 图形选择监听骨架
- 构建与注册脚本

本版本暂未完成：

- draw.io 桌面程序启动
- URL 模式嵌入编辑器
- SVG 插入与替换
- 自动保存监听与回写

后续增量：

- 已在后续开发中补上元数据绑定 MVP，可作为 `v0.2.0-metadata` 的起点
